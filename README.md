# APLICATIVO-WEB-DE-GESTI-N-Y-SEGUIMIENTO-DE-PR-CTICAS
Aplicativo web para la gestión de prácticas pedagógicas del programa de Licenciatura en Educación Infantil de la UDI: asignaciones, documentos legales, bitácoras y evaluaciones independientes, con trazabilidad para procesos de autoevaluación y acreditación.
